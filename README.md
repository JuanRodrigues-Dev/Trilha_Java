# ☕ Trilha Java

Bem-vindo ao repositório **Trilha Java**! Este espaço é dedicado aos meus estudos e práticas de desenvolvimento em back-end, documentando meu progresso desde os fundamentos da linguagem até conceitos avançados de Orientação a Objetos.

Grande parte deste repositório contém exercícios, lógicas e implementações baseadas na **Maratona Java** [cite: 1]. O objetivo aqui é manter um registro limpo e organizado da minha evolução técnica.

## 🚀 Tecnologias e Ferramentas
* **Linguagem:** Java
* **Paradigma:** Programação Orientada a Objetos (POO)
* **IDE:** IntelliJ IDEA

## 📚 Estrutura de Estudos
O repositório está organizado acompanhando uma jornada de aprendizado progressiva:

### 1. Fundamentos da Linguagem
* Tipos primitivos, operadores lógicos e matemáticos
* Estruturas condicionais (`if`, `switch`)
* Estruturas de repetição (`for`, `while`, `do-while`)
* Arrays uni e multidimensionais

### 2. Orientação a Objetos (Core)
* Classes, Atributos e Métodos
* Construtores e Blocos de Inicialização
* Modificadores de Acesso, `static` e `final`
* Associação entre objetos

### 3. POO Avançada
* Herança e Polimorfismo
* Sobrescrita (`@Override`) e Sobrecarga de métodos
* Classes Abstratas
* Interfaces
* Enumerações
